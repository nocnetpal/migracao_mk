# NE8000 ↔ DM4170 — enlace de gerência 192.168.15.48/30 (2026-08-07)

> Criado para dar gerência direta ao DM4170 (Datacom) via NE8000, sem depender de switch.
> Reutiliza o segmento `192.168.15.48/30` do antigo EoIP "GERENCIA SW DATACOM" (morto).

## Endereçamento

| Lado | IP | Onde |
|---|---|---|
| NE8000 (VS BGP_NETPAL) | `192.168.15.49/30` | GE0/1/3 (atribuída à VS em 2026-08-07) |
| DM4170 (Datacom) | `192.168.15.50/30` | MGMT — **aplicar na noite** (troca do 192.168.0.25/24) |

## Config aplicada no NE8000 (VS BGP_NETPAL)

```
interface GigabitEthernet0/1/3
 description MGMT-DM4170-SW_SERVIDORES
 undo shutdown
 ip address 192.168.15.49 255.255.255.252
commit
```

Atribuição: `admin` → `virtual-system BGP_NETPAL` → `assign interface GigabitEthernet0/1/3`.

## Validação

- `display ip interface brief | include 192.168.15.49` → só GE0/1/3 com o IP (sem duplicidade;
  o "The address already exists" foi repetição de comando, confirmado por
  `display current-configuration | include 192.168.15.49` na VS e no chassi — sem outra ocorrência).
- GE0/1/3 down/down: sem transceiver/cabo por enquanto (decisão do usuário: "não pluga nada").

## ⚠️ Pendência para a noite

- Trocar a MGMT do DM4170 de `192.168.0.25/24` para `192.168.15.50/30` **somente quando a MGMT
  for ligada ao enlace** (fazer isso cedo derruba o acesso SSH de bancada — notebook está em
  192.168.0.49). Para testar antes: colocar o notebook em 192.168.15.x ou plugar a MGMT na GE0/1/3.
