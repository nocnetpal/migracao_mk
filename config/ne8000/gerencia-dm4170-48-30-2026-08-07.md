# NE8000 ↔ DM4170 — enlace 192.168.15.48/30 + trunk VLAN 16 (2026-08-07)

> Criado para dar gerência direta ao DM4170 (Datacom) via NE8000. A **GE0/1/3** virou o trunk
> do DM4170 (gerência + tráfego em subinterfaces). Reutiliza o segmento `192.168.15.48/30`
> do antigo EoIP "GERENCIA SW DATACOM" (morto).

## Endereçamento

| Lado | IP | Onde |
|---|---|---|
| NE8000 (VS BGP_NETPAL) — gerência | `192.168.15.49/30` | **subinterface GE0/1/3.48** (dot1q 48) — shutdown |
| DM4170 (Datacom) — gerência | `192.168.15.50/30` | MGMT — **aplicar na noite** (troca do 192.168.0.25/24) |
| NE8000 — gateway /27 | `177.72.104.1/27` | **subinterface GE0/1/3.16** (dot1q 16) — shutdown (trunk DM4170) |

## Config aplicada no NE8000 (VS BGP_NETPAL) — 2026-08-07

```
interface GigabitEthernet0/1/3
 undo ip address
quit
interface GigabitEthernet0/1/3.16
 vlan-type dot1q 16
 ip address 177.72.104.1 255.255.255.224
 shutdown
quit
interface GigabitEthernet0/1/3.48
 vlan-type dot1q 48
 ip address 192.168.15.49 255.255.255.252
 shutdown
quit
commit
```

Atribuição da porta à VS: `admin` → `virtual-system BGP_NETPAL` → `assign interface
GigabitEthernet0/1/3` (2026-08-07).

> ⚠️ A **MGMT do DM4170 ficou sem cabo** (decisão do usuário). O `.50/30` e a subinterface
> `.48` ficam **preparados**; a gerência só funciona quando existir caminho com a VLAN 48
> (MGMT OOB não taggeia — vale para topologia futura). O trunk `.16` é o caminho principal.

## Validação (2026-08-07)

- `display ip interface brief | include GigabitEthernet0/1/3`:
  - `GE0/1/3` — unassigned, down
  - `GE0/1/3.16` — `177.72.104.1/27`, administratively down ✅
  - `GE0/1/3.48` — `192.168.15.49/30`, administratively down ✅
- Sem duplicidade do `.49` (checado na VS e no chassi; o "The address already exists" foi
  repetição de comando).

## ⚠️ Pendência para a noite

- Trocar a MGMT do DM4170 de `192.168.0.25/24` para `192.168.15.50/30` **somente quando
  houver cabo/caminho** (fazer cedo derruba o SSH de bancada — notebook em 192.168.0.49).
- Na virada: `undo shutdown` na GE0/1/3.16 + OSPF do /27 (após RB3011 parar de anunciar).
